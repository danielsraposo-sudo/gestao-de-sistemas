# Gestão de Sistemas

Sistema de gestão de clientes, cobranças e financeiro.

## Publicação

Este projeto pode ser publicado pelo GitHub Pages usando a branch `main` e a pasta raiz `/`.

## Segurança

- Não inclua backups de clientes ou dados pessoais no repositório.
- Não inclua Secret Key, service_role ou senha do Supabase.
- A aplicação usa apenas a Publishable Key no navegador e depende do RLS do Supabase para proteger os dados.

## Uso

Abra o sistema pelo GitHub Pages. O modo local continua disponível caso a nuvem esteja indisponível.
