# Gestão de Sistemas

Sistema web para gestão de clientes, cobranças, pagamentos e financeiro.

## Publicação

Este projeto é publicado pelo **GitHub Pages** a partir da branch `main`, usando a pasta raiz `/`.

## Acesso

O site do projeto é:

`https://danielsraposo-sudo.github.io/gestao-de-sistemas/`

## Recursos desta versão

- Tela de entrada com identidade visual do Gestão de Sistemas
- Layout responsivo para computador, tablet e celular
- Modo local para continuar trabalhando sem a nuvem
- Integração opcional com Supabase
- Backup e restauração dentro de Configurações
- Ícone e instalação como aplicativo compatível com navegadores que suportam PWA
- HTTPS pelo GitHub Pages

## Segurança

- Nunca coloque Secret Key, service_role, senha do banco ou credenciais administrativas neste repositório.
- A aplicação pode usar somente a Publishable Key no navegador.
- Dados de clientes e backups não devem ser enviados ao repositório.

## Observação sobre o Supabase

A integração com a nuvem depende da disponibilidade do endpoint do projeto Supabase configurado na aplicação. O modo local permanece disponível quando a nuvem não estiver acessível.
